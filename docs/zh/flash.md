# 下载到控制器

在连接开发板的电脑上，使用 Chrome 或 Edge [打开交互课程](/zh/#lesson-01)。

1. 选择课程，打开 **连接开发板**。
2. 插上 USB 数据线，点击 **连接并下载本课**，选择控制器的 USB 串口。
3. 网页获取并校验已发布的课程固件，通过 USB 写入后再次校验。切换下载其他课程时，会复用已有连接。
4. 控制器重启，页面尝试重新连接日志。按 **接下来试一试** 中的提示操作，并观察本课的预期表现。

设备卡片只有收到控制器应答后，才会显示它实际运行的课程；下载完成或 USB 已连接本身不能确认程序启动。日志区提供 **读取设备信息**、**重启控制器** 和命令输入；身份识别与重启需要新版课程固件。遇到问题时，面板会显示对应的排障说明。

正常下载无需安装软件、配置 ESP-IDF 或启动本地服务。已发布固件使用课程默认参数；网页模拟滑条不会改变固件内容。

## 首次安装与恢复

页面首先尝试自动进入下载模式。若无法连接，按住 **B（BOOT）**，按下并松开 **R（RESET）**，再松开 B。重新选择 USB 设备并下载；如果写入后程序未启动，再按一次 R。

下载会替换当前程序。分段写入会保留本项目分区布局中的 NVS 参数，但不保证兼容其他固件的分区布局。

## 自定义程序

修改 C 源码或编译参数需要重新构建固件。可选的本地配套服务提供自定义编译和 Wi-Fi 操作，不是下载已发布 USB 课程固件的前提。
