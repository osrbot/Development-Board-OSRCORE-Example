# 从仿真到真实开发板

使用电脑上的 Chrome 或 Edge 和 USB 数据线[打开交互课程](/zh/#lesson-01)。不需要编译器、安装软件或启动本地服务。

## 安装课程

选择课程，打开代码区的 **下载到开发板**，点击 **连接并下载本课**，选择控制器的 USB 串口。网页写入并校验已发布固件，重启控制器并尝试重新连接。完成后回到课程，展开底部 **设备串口**。

首次使用实时参数需要安装一次新版课程固件。切换另一课时需要安装对应固件；在同一课内调整支持的参数不需要重新下载。

## 应用与保存参数

标为 **实板可调** 的参数支持 USB 更新：LED 亮度与间隔、蜂鸣器频率与时长、舵机脉宽、编码器每转计数、Kp、任务周期，以及姿态融合权重。

1. 调整网页参数，观察仿真。
2. 点击 **应用到开发板**。页面显示设备回执中的当前值；仅发送命令不算成功。课程在下一次更新周期使用新值。
3. 点击 **保存到开发板**，重启后仍保留这些值。只应用、不保存时，重启会恢复已保存值或默认值。

应用舵机脉宽会产生动作；保存后重启也会恢复该脉宽。模拟倾角、遥控通道和模拟负载等输入不会作为控制命令发送到实板。

网页会先核对设备报告的课程。旧固件需要更新；应答超时时，可点击 **读取设备信息** 核对当前值后再试。

## 一个控制台

底部控制台分别显示 **仿真输出** 和 **设备串口**。设备串口集中提供真实日志、命令输入、设备信息、重启和断开操作。关闭下载面板或切换网页课程会保留连接；不需要观察输出时可收起。

## 恢复下载

安装器先尝试自动进入下载模式。无法连接时，按住 **B（BOOT）**，按下并松开 **R（RESET）**，再松开 B。重新选择 USB 串口后重试；如果写入后程序未启动，再按一次 R。

下载会替换程序，并保留本项目分区布局中的 NVS，包括已保存的课程参数。安装器提供串口访问、端口占用和固件校验等分类排障说明。

## 源码

教学代码用于讲解课程，并随网页参数变化。**应用到开发板** 发送支持的参数，不会编译或执行任意 C 代码修改。修改程序逻辑仍需使用 ESP-IDF 构建固件。
